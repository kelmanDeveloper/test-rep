# Outfit Picker

Vue 3 приложение для выбора нарядов с множественным и одиночным выбором элементов.


- **Vue 3** - Composition API (script setup)
- **Vite** - сборщик и dev-сервер
- **JavaScript** - без TypeScript

## Структура проекта

```
src/
  app/
    App.vue                 # Корневой компонент приложения
  
  shared/
    ui/
      ItemCard.vue          # Карточка элемента
      ItemGrid.vue          # Сетка элементов
      PanelFrame.vue        # Панель с заголовком и контентом
  
  features/
    outfit-picker/
      model/
        constants.js        # Константы (списки элементов, лимиты)
        useSelection.js     # Композаблы для выбора элементов
      ui/
        OutfitPickerPage.vue # Главная страница выбора наряда
```


### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для production

```bash
npm run build
```

### Превью production сборки

```bash
npm run preview
```

##  Функциональность

### Множественный выбор (User items)
- Выбор до 6 элементов из списка пользовательских предметов
- Отображение выбранных элементов в верхней левой панели
- Счетчик выбранных элементов: `selected: N / 6`

### Одиночный выбор (Choice items)
- Выбор одного элемента из списка предметов выбора
- Отображение выбранного элемента в верхней правой панели

### Адаптивный дизайн
- Полностью адаптивный интерфейс для всех размеров экранов
- Оптимизация для мобильных устройств, планшетов и десктопов

##  Особенности

- **Composition API** - используется только `<script setup>` синтаксис
- **Минималистичный дизайн** - черные контуры на белом фоне
- **Алиасы путей** - используется `@/` для импортов из `src/`
- **Реактивность** - полная реактивность через Vue 3 Composition API

## Адаптивность

- **Десктоп** (> 1024px): 4 колонки в сетке элементов
- **Планшет** (≤ 1024px): 3 колонки в сетке элементов
- **Мобильный** (≤ 768px): 2 колонки, вертикальная компоновка панелей
- **Маленький мобильный** (≤ 480px): оптимизированные размеры и отступы
